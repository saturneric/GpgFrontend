## 2.1.14 (2026-11-17)

This update fixes security problems and bugs in GpgFrontend 2.1. Everyone
who stays on 2.1, including Qt5 users, should update. Updating from 2.1.13
keeps your keys and settings.

2.1 receives security fixes only, until 2027-12-31. GpgFrontend 2.2 is the
current release: please move to it if your system supports it.

### Security fixes

- **Extracting encrypted archives is safe.** A specially crafted `.tar.gpg`
  file could write into files outside the folder you extracted it to.
- **Signature results are more reliable.** When a message or a signed file
  has extra text around the signed part, GpgFrontend no longer shows the
  signature result as if it covered that text. A signature from a key that
  GnuPG marks as never valid is reported as a possible forgery.
- **Signing uses the key you chose.** If that key cannot sign, GpgFrontend
  stops with an error instead of quietly signing with another key.
- **Encryption never leaves something out silently.** If a recipient, a file,
  or a file inside a folder cannot be included, the operation fails.
- **Revocation certificates only revoke the key you are looking at.** Key
  Details refuses a certificate made for a different key.
- **No more accidental data loss.** Decrypting over an existing folder keeps
  the old one beside the new one, two files of one batch can no longer
  overwrite each other's result, and a text operation's result goes back to
  the tab it came from, even if you switched tabs meanwhile.
- **Secrets are wiped from memory** after use in more places.
- Crash fixes when several operations run at once, and when a window is
  closed while an operation started from it is still running.

### Other fixes

- Some actions that failed (deleting keys, exporting a subkey, creating a
  revocation certificate) were reported as successful. They now report the
  error.
- Export Shortest Secret Key exports the short key again.
- A file that cannot be opened is reported by name instead of failing in
  an unclear way.
- GnuPG commands waiting for a passphrase are no longer cut off after 30
  seconds.
- Copying a folder into the file panel no longer follows links.
- A verification result is cleared as soon as you edit the text it was
  about.
- Closing Settings no longer restarts the application after you declined to
  save your open tabs.
- Restarting from an AppImage starts the AppImage again.

### Update check

- If you allowed it, GpgFrontend checks for updates when it starts, as it
  always meant to, and tells you once when a newer stable release is out.
  It asks the official update server and downloads nothing by itself.

### Downloads

- The Windows packages include GnuPG 2.5.24 (up from 2.5.21). Windows has an
  installer (MSI) and a portable ZIP again, built and signed like every other
  file of the release.
- There is no macOS 14 build any more: the build service no longer offers
  macOS 14. Use 2.1.13 there, or move to a newer macOS.
