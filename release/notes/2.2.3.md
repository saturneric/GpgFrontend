## 2.2.3 (2026-10-24)

This update reworks email, modules and profile packages, and makes
encryption safer. Everyone using 2.2 should update. Your profiles, keys
and settings from 2.2.2 carry over unchanged.

### Security fixes

- **Modules are checked before they load.** Modules are now signed
  packages and can only use the features they declare. Modules from other
  makers run only after you approve them. The module manager shows which
  modules were refused and why.
- **Profile packages are rebuilt.** An exported profile always needs a
  passphrase, a damaged or changed package is detected, and opening one
  leaves no unencrypted copy on disk.
- **Secrets are handled more carefully.** Passphrases are wiped from memory
  after use, and cached passphrases are kept apart for each key database.
- **No partial or unchecked output.** Decrypted files and archives are
  written only after the integrity check passes, so you never get a
  half-written or changed result. A failed or cancelled operation leaves
  nothing behind.
- **Harder to encrypt to the wrong people.** An optional single-recipient
  mode stops keys you ticked earlier from being added as extra recipients,
  and you can choose to confirm before encrypting to more than one person.
  When encryption is not possible, you are told which key is the problem
  and why.
- **Up-to-date OpenPGP.** Post-quantum encryption now follows the final
  standard, and you are warned before mixing post-quantum and classic
  recipients. Keys and signatures are checked more strictly. Signatures
  made by keys that are not allowed to sign are shown as such.

### What's new

- **Email reworked.** Send signed and encrypted mail and read your
  mailboxes from your mail account. Writing and sending is smoother, and
  you can see more clearly which parts of a message are signed or
  encrypted.
- **See what is inside OpenPGP data.** A new window shows the structure of
  any message, key or signature.
- **Profile packages work on every system.** Export on one operating
  system and open on another, with your key databases working.
  Settings that only fit one computer stay behind.
- **Key database changes apply right away,** with no restart.
- **Temporary profiles** that are deleted completely when you close their
  window.
- **Right-to-left text** is detected automatically.
- **A simpler toolbar.** The variants of Encrypt and of Decrypt share one
  button each.
- **Redesigned key group management.**
- **New languages:** Polish and Turkish.

### Other fixes

- Unsaved text is no longer lost when you quit.
- A message signed by someone whose public key you do not have now
  decrypts, with a warning that the signature could not be checked.
- After a restart, the system keychain asks to be unlocked instead of
  showing an error.
- Windows: importing post-quantum secret subkeys works again. The Windows
  packages include GnuPG 2.5.24.
- The built-in rPGP engine decrypts files of any size using little memory.
- Several crashes when closing windows and quitting are fixed.

### Before you update

- **Qt5 is no longer supported in 2.2.** Qt is the toolkit GpgFrontend's
  windows are built with. From 2.2.3 on, GpgFrontend needs Qt 6.5 or
  newer. If you need Qt5, stay on 2.1, which still supports it.
- **Modules made for 2.2.2 or older will not load.** Their makers need to
  rebuild and sign them for this version.
