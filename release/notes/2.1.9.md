## 2.1.9 (2025-06-19)

This is a large security update. It protects secrets in memory and data on
disk much better. Everyone using 2.1 should update, but read "Before you
update" first.

### Security improvements

- **Secrets in memory are better protected.** Passwords and other
  sensitive data are kept in protected memory and wiped after use. You can
  choose how strict this protection is.
- **Stored data is encrypted.** Sensitive data that GpgFrontend saves on
  disk is protected with modern, strong encryption.
- **Key packages are better protected.** Key packages (files for moving
  keys to another device) now use stronger encryption and need a PIN.
- **Optional PIN to open the app.** For very sensitive work you can require
  a PIN to unlock GpgFrontend, and have its own protection keys replaced on
  a schedule.
- **Windows files are signed.** All Windows programs and installers carry a
  digital signature, so Windows no longer warns about an "Unknown
  Publisher".
- **Optional self-check.** When it starts, GpgFrontend can check that its
  important libraries have not been changed by someone else.

### What's new

- **Choose the signing subkey.** If your key has more than one subkey for
  signing, you can pick which one to use each time you sign.
- **Key generation profiles.** Save your key generation settings as a
  profile and use them again later.
- **Owner trust for key groups.** Owner trust says how much you trust a
  key's owner. You can now set it for a key group.
- **Sym. Encrypt** in the toolbar and menus encrypts with a password only,
  without a key.
- **Update check without GitHub.** You can choose to check for updates on
  GpgFrontend's own servers instead of GitHub.

### Other fixes

- AppImage: all known problems with secure connections (TLS/SSL) are fixed.
- Many interface improvements and bug fixes.

### Downloads

- Windows has a new MSIX installer.
- There is now an AppImage for Linux computers with ARM64 processors.

### Before you update

- **Data saved by older versions cannot be used.** GpgFrontend now stores
  its own data in a new, protected way. Data that older versions saved for
  the app cannot be read by 2.1.9.
