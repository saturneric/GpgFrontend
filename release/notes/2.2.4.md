## 2.2.4 (2026-10-27)

This quick follow-up to 2.2.3 fixes several serious problems. Everyone
using 2.2.3 should update. Your profiles, keys and settings carry over
unchanged.

### Important fixes

- **Password-only (symmetric) encryption of files works again.**
- **Encrypted email reaches every recipient.** In the email module,
  encrypting and signing used only the first selected key, so the other
  recipients could not read the message.
- **Certifying uses the key you chose.** Certifying means signing someone
  else's key to confirm it is theirs. Your default key was used instead of
  the one you picked.
- **The main window no longer freezes** when GnuPG stops responding.
- **The update check waits for your permission.** It could run before you
  agreed to it.
- A crash is fixed, and GnuPG now starts in temporary profiles on
  macOS.

### What's new

- **A new key generation wizard,** with three simple choices (Modern,
  Compatibility and Hybrid encryption), an Expert Mode for every detail,
  and Quick Generate to make a key in one click.
- **Guided wizards** for creating and exporting profiles, and for
  exporting and importing key packages. You can pick which keys to import
  from a package.
- **A recycle bin for key databases.** Removed key databases can be
  restored from the settings.
- **HTML mail preview** in the email module (Windows, macOS and Flatpak).
  It is safe by default: no scripts, no content loaded from the internet,
  and links open only after you confirm.
- **Easier email account setup.** A wizard finds your mail servers from
  your email address and tests the connection.
- **A redesigned window for certifying keys.**

### Other fixes

- When you sign files with a key that has more than one signing subkey,
  you can choose which one to use.
- Key categories and the default key database are kept when you export
  and import profiles.
- The window that shows what is inside OpenPGP data recognizes
  post-quantum algorithms.
- Profile files can only be read by you.
- The key management window opens much faster when you have many keys.
