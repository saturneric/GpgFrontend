## 2.1.11 (2026-04-10)

This update adds post-quantum encryption, makes the app leaner, and checks
for updates only when you ask it to. Everyone using 2.1 should update.

### What's new

- **Post-quantum encryption subkeys.** You can create hybrid encryption
  subkeys (Kyber), a type designed to stay safe against future quantum
  computers. This needs GnuPG 2.5 or newer.
- **A leaner app.** Email, key server and update check features now come
  as built-in modules. You can turn these modules off or remove them.
- **Safer module loading.** By default, GpgFrontend loads only the modules
  that come with it.
- **Clearer signature results.** The result of checking a signature is
  easier to understand.

### Update check

- The update check is off by default in the first-start wizard.
- Checking for updates now happens in a separate window that you open
  yourself, so GpgFrontend uses the network less.

### Other fixes

- Problems in the windows for creating keys and subkeys are fixed.
- The libraries GpgFrontend uses were updated.

### Downloads

- The Windows packages include GnuPG 2.5.18.
- The build for Intel Macs is now made for macOS 15, and there is a new
  build for macOS 26.
