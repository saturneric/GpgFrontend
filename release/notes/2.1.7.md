## 2.1.7 (2025-02-04)

This update makes it easier to work with many files, simplifies key
generation, and makes the portable version truly portable. Everyone using
2.1 should update.

### What's new

- **Work on many files at once.** In the file panel you can select several
  files and process them together.
- **Simpler key generation.** The windows for creating keys and subkeys
  were redesigned to be clearer and more compact.
- **Choose your toolbar buttons.** You can pick which buttons the toolbar
  for encrypting, decrypting, signing and verifying shows.
- **A truly portable app.** The portable version keeps its key database
  and settings in its own folder, so it runs anywhere without being
  installed.
- **More control over key databases.** You can change the default key
  database, and key databases can use paths relative to the app, so they
  are easy to move.
- **GnuPG's background programs are stopped when you quit.** The option
  Kill all gnupg daemon at close in GnuPG Controller turns this on or off.
- **The update check asks first.** On first start, and at each start until
  you decide, GpgFrontend asks whether it may check for updates.
- **File panel:** choose which column to sort by, and switch between text
  (ASCII) and binary output for file operations.
- **Key list:** the creation date is shown as year-month-day, so sorting by
  date works. The columns and spacing were tidied up.
