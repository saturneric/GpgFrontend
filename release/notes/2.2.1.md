## 2.2.1 (2026-06-29)

This release makes GpgFrontend 2.2 ready for everyday use. It is now the
recommended version for everyone, and users of 2.1 are encouraged to move
to it.

GpgFrontend 2.2 can work with two OpenPGP engines: GnuPG, and a new
built-in engine called rPGP that also works when GnuPG is not installed.

### Security fixes

- **Secrets are wiped from memory (rPGP).** Keys, passphrases and
  decrypted text are kept in protected memory throughout the app and wiped
  as soon as they are no longer needed.
- **Passphrase fields are cleared** right after the passphrase is used
  (rPGP).
- **Cached passphrases are protected (rPGP).** They expire after 10
  minutes without use, and after 2 hours at most. You can change both
  times. They are kept in memory that is never written to disk, and wiped
  after use.
- **Key databases can only be read by you (rPGP).**
- **Safer input.** Names and comments in user IDs are checked for bad
  characters, and a failed decryption no longer overwrites the text in the
  editor.

### What's new

- **Choose your default engine:** GnuPG or the built-in rPGP.
- **Cancel a running operation** from the waiting window.
- **Operation report.** A report card shows the signers, the recipients,
  whether each signature is valid, and a checksum (SHA-256) of the data.
  You can zoom in and save it as a PNG image.
- **Passphrase strength meter (rPGP),** with a second field to confirm a
  new passphrase.
- **Editor:** a live SHA-256 checksum of the text, and settings for the
  font and tab size.
- **Key generation:** choose key version 4 or 6 (rPGP), create a random
  anonymous identity, and pick from profiles grouped by algorithm.
- **Simpler signing.** One signing key picker shows only keys and subkeys
  that can sign, starting from the keys you ticked in the key list.
- **Better feedback.** Key details show the key's format version (rPGP),
  exports are confirmed, and a new log viewer has highlighting and
  filters.
- The About window shows build information and details of the rPGP
  engine.
- Windows that come from modules are now translated like the rest of the
  app.

### Other fixes

- **Quitting is more reliable (GnuPG).** All of GnuPG's background
  programs are stopped when you quit. This fixes hangs and leftover
  processes, especially on Windows.
- **Editing keys and smart cards no longer gets stuck (GnuPG).**
- **Decrypting an encrypted folder no longer loses files (GnuPG).**
- **Damaged stored data is set aside, not deleted at once.** A background
  check moves damaged or unreadable items aside and deletes them only
  after a while. Nothing is lost if, for example, a needed key is missing
  for a short time.
- Signing with several keys uses all of them, not just the first (rPGP).
- Cancelling a passphrase prompt is no longer reported as an error. The
  prompt closes by itself after 120 seconds and shows a countdown (rPGP).
- rPGP: every signature on a message with several signers is checked and
  listed, secret subkeys are no longer dropped on import, error messages
  are clearer, and key generation reports the right result.
- Key generation windows stay open when generation fails, so you can try
  again without typing everything again.

### Downloads

- Windows files are signed with a new code signing certificate. The
  Windows packages include GnuPG 2.5.20.
- The Linux AppImage shows its icon properly on the desktop and in the
  file manager.

### Before you update

- **Coming from 2.1?** GpgFrontend 2.2 protects the data it stores for
  itself in a new way. Some of that data from 2.1 (such as certain
  settings or cached data) may not be readable. Your OpenPGP messages,
  signatures, encrypted files and GnuPG keys are not affected.
