## 2.1.8 (2025-04-19)

This update adds key groups, smart card support and more. It also needs a
newer GnuPG. Everyone using 2.1 should update.

### What's new

- **Key groups.** Put several public keys in a group and encrypt to the
  whole group at once. A group works like a single key, and groups can
  contain other groups.
- **Smart cards.** See the details of an OpenPGP smart card, do basic tasks
  on it, and create keys directly on the card. This needs GnuPG 2.3.0 or
  newer.
- **Additional decryption subkeys.** You can add a subkey from another key
  pair to your key, so that the other key can also decrypt messages sent
  to you. This needs GnuPG 2.4.1 or newer.
- **Key details at a glance.** Point at a key in the key list to see a
  short summary of it.
- **Clearer wording.** Many parts of the interface and their names were
  reworked to be less confusing.
- **GpgFrontend looks after gpg-agent.** It starts and stops gpg-agent
  (GnuPG's background program for secret keys and passwords) by itself.
- **Password window check.** GpgFrontend looks for a program that shows
  GnuPG's password window (pinentry). If none is found, it asks you to
  install one.

### Other fixes

- Information about subkeys is now found correctly when you decrypt or
  verify.
- Flatpak: the long-standing "No Pinentry" problem, where no password
  window could appear, is fixed.
- Many other bugs were fixed.

### Downloads

- The Linux AppImage can now be used in portable mode.
- A new universal portable ZIP contains both the Windows and the Linux
  version. Both share one set of settings.

### Before you update

- **GpgFrontend now needs GnuPG 2.2.0 or newer.** GnuPG 2.4.7 or newer is
  recommended.
