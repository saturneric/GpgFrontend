## 2.2.5 (2026-11-16)

This update fixes security problems and bugs in GpgFrontend 2.2. Everyone
using 2.2 should update.

### Security fixes

- **Extracting encrypted archives is safe.** A specially crafted `.tar.gpg`
  file could put files outside the folder you extracted it to.
- **Signature results are more reliable.** When a message has extra text
  around the signed part, GpgFrontend no longer shows the signature result
  as if it covered that text. Signatures from revoked or expired keys,
  expired signatures and signatures using weak hash algorithms are now
  reported as such.
- **Signing uses the key you chose.** If that key cannot sign, GpgFrontend
  stops with an error instead of quietly signing with another key.
- **Encryption never leaves something out silently.** If a recipient, a file,
  or a file inside a folder cannot be included, the operation fails and tells
  you which one.
- **Keys are harder to fake.** A name or email address is only shown on a key
  when the key's owner has signed it. Importing an older copy of your secret
  key no longer removes its passphrase.
- **Secrets are wiped from memory.** Decrypted text, secret keys and
  passphrases are cleared from memory after use.
- **No more accidental data loss** when saving or decrypting over existing
  files, or when deleting a profile.
- Many crash fixes when several operations run at once or the app is closing.

### Other fixes

- A decrypted message is shown even when its signature cannot be verified;
  the signature problem is reported next to it.
- Some actions that failed (deleting keys, exporting a subkey, creating a
  revocation certificate) were reported as successful. They now report the
  error.
- Export Short Private Key exports the short key again.
- Key files up to 16 MiB can be imported.
- The window no longer freezes during long key operations.
- Confirmations for risky actions now default to Cancel.

### Updates

- GpgFrontend now checks the digital signature on update information before
  showing it to you.
- In Settings > Updates you can opt in to beta versions and choose which
  offered update to install.

### Before you update

- **If you use the built-in OpenPGP engine (rPGP):** once 2.2.5 has opened
  your keys, you cannot go back to 2.2.4. If you use GnuPG, this does not
  affect you.
