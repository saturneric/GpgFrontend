## 2.1.6 (2024-12-03)

This update adds many new features for keys and key databases, and fixes
bugs. Everyone using 2.1 should update.

### What's new

- **Revoke or delete subkeys and user IDs.** A subkey is an extra key
  inside your key pair. A user ID is a name and email address on a key.
- **More than one key database.** A key database is a folder where your
  keys are kept. You can now have several and switch between them quickly.
- **Export a single subkey.**
- **Work with saved emails (early version).** You can encrypt, decrypt and
  verify emails saved as EML files. Feedback on this feature is welcome.
- **Better use of keys.openpgp.org.** GpgFrontend can now talk to this
  public key server directly. When you check a signature and the signer's
  public key is missing, it can find and import the key from there. It can
  also check whether your public key is published there (off by default).
- **New key types.** The secp256k1 algorithm is supported, and Ed448 can be
  used for the main (primary) key.
- The update check shows the release notes of the new version.
- You can open a text file by dragging it into the text editor.
- The interface was improved in many places.
- The English, Chinese (Simplified) and German translations were improved.

### Other fixes

- Many bugs were fixed to make the app more stable.
- The Windows uninstaller handles special characters correctly.
- The Windows portable package has a clearer folder layout.

### Downloads

- There is now a build for macOS 15.
- There is no macOS 12 build any more: the build service is dropping
  macOS 12. You can still build GpgFrontend yourself there.
- Nightly builds are now published. They let you try upcoming changes early
  and help find problems before a release.
