## 2.1.12 (2026-05-25)

This update improves the text editor, the file panel and the first-start
wizard, and fixes crashes. Everyone using 2.1 should update. Like other
2.1 updates, it brings fixes and interface improvements taken from newer
versions, but no big new features.

### What's new

- **A better text editor.** Line numbers, the current line highlighted,
  more information in the status bar, and more reliable recovery of
  unsaved text.
- **A better file panel.** Drag and drop, create files and folders, move
  items to the Trash, and easier navigation.
- **A refreshed first-start wizard.**
- **Appearance changes apply at once,** without a restart.
- Windows reopen where you left them, also with more than one screen.
- Creating keys and choosing algorithms is easier.
- The windows for managing key databases were improved.
- Output file names for encrypting, decrypting, signing and verifying are
  chosen better.
- **Russian language.** Many missing translations in other languages were
  also filled in by automatic translation. If a translation sounds wrong,
  you are welcome to help improve it.

### Other fixes

- AppImage: crashes caused by two copies of the OpenSSL library getting in
  each other's way are fixed.
- Restoring the editor's tabs and unsaved text works reliably.
- Many smaller interface and stability fixes.

### Downloads

- This is the last release signed with the old Windows code signing
  certificate. The next release uses a new one.
