## 2.1.10 (2025-10-25)

This update fixes random crashes on Linux and adds a few features. Everyone
using 2.1 should update.

### What's new

- **Quick access to drives.** In the file panel, a menu lists the drives
  that are currently connected, so you can jump to them.
- **Photo IDs.** Key details show the photos stored in a key.
- **Two new settings for advanced users** in the `ENV.ini` file: choose
  which password program (pinentry) GnuPG uses, and an offline mode that
  stops GnuPG from using the network.

### Other fixes

- **Random crashes while encrypting or decrypting on Linux are fixed.**
- Your own key generation profiles are now always saved.
- The libraries GpgFrontend uses were updated for better security and
  stability.

### Before you update

- **GpgFrontend's own password window was removed** to make the app safer.
  Passwords are now always asked for by GnuPG's password program
  (pinentry).
