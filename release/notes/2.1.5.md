## 2.1.5 (2024-10-03)

This update fixes a crash on macOS and a few smaller problems. Everyone
using 2.1, and especially macOS users, should update.

### Fixes

- **GpgFrontend no longer crashes when it starts on macOS.**
- The main window no longer has a minimum size.
- Parts of the window that come from modules now change language when you
  switch the language.
- The Italian translation was updated.

### Downloads

- From this release on, the download files are signed with a new key. You
  can use it to check that a file really comes from GpgFrontend. Its
  fingerprint is `12F7E8858CF15BEC9975FF3C5CA3DA246843FD03`.
